这个网站能做什么

    
自建的小站：聊天、看图、画图、出动图、联网、写代码。数据存在自己的服务器，图片存对象存储。


    

      

        
聊天

        
    
          
  • 多模型切换，推理强度可调（低 → 最高，按模型上限）
    • 
          
  • 流式输出、随时停止、一键复制
    • 
          
  • 每条回复标注模型与档位
    • 
          
  • 对话记住设置：模型 / 档位 / 各模式随对话保存，别人打开同一对话也一样
    • 
        

      


      

        
画图

        
    
          
  • 画图开关打开后，说想要什么就出图；会先理解上文再写提示词（不再照抄你的原话）
    • 
          
  • 图片下方可展开「模型写的提示词」，看它到底怎么描述的
    • 
          
  • 一次要多张：说「画 3 张不同风格的猫」，会分别生成 3 张（不是拼图）
    • 
          
  • 改图：输入框挂着图再说需求，就基于那张图改
    • 
          
  • 参数：尺寸 / 质量 / 背景 / 格式，鼠标移到「画图」标签上直接调
    • 
        

      


      

        
动图（GIF）

        
    
          
  • 说「做个动图 / GIF / 让它动起来」即可
    • 
          
  • 帧数 2–16、帧间隔可调（鼠标移到「动图」标签上）
    • 
          
  • 挂着图说「让它动起来」＝ 把这张图做成动图
    • 
        

      


      

        
图片

        
    
          
  • 粘贴或上传图片提问，支持多张；单张上限 50MB
    • 
          
  • 原图开关：跳过压缩，保留细节
    • 
          
  • 点图片放大预览，可下载 / 复制；动图复制会退化为复制链接
    • 
        

      


      

        
联网

        
    
          
  • 开启后自动检索网页并给出引用链接
    • 
          
  • 适合问时效性内容
    • 
        

      


      

        
编程模式

        
    
          
  • 代码写进右侧面板，不刷屏对话
    • 
          
  • 多文件标签、直接编辑、一键复制全文、下载
    • 
          
  • HTML/SVG 预览，自动内联同会话的 css/js
    • 
        

      


      

        
对话与项目

        
    
          
  • 对话共享给所有人；可建 私人对话（仅你和管理员可见）
    • 
          
  • 项目＝文件夹，带项目指令，对话可拖进去
    • 
          
  • 自定义指令：告诉 AI 你的偏好和背景，只对自己生效
    • 
        

      


      

        
长对话

        
    
          
  • 底部圆环显示上下文占用（绿 / 黄 / 红）
    • 
          
  • 交接文档：把上文压成摘要，之后只发摘要，旧内容仍可回看
    • 
        

      

    


    

      说明：所有内容只在浏览器和服务器之间流转，不读取你电脑上的文件；图片经浏览器直传对象存储，
      单张上限 50MB。私人对话管理员可见（用于管理，不用于偷看）。
